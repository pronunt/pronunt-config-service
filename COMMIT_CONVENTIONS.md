# Commit Conventions

Use Conventional Commits for this repository.

Format:

`type(scope): short summary`

Examples:

* `feat(config): add dependencies endpoint`
* `fix(data): correct service criticality mapping`
* `refactor(service): simplify config loading`
* `docs(readme): update local setup steps`
* `chore(deps): bump FastAPI`
* `test(config): add config endpoint tests`

Recommended types:

* `feat`
* `fix`
* `refactor`
* `docs`
* `chore`
* `test`
* `ci`
* `build`
